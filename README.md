# Учёт студентов по лицу — версия 1

Камера у входа узнаёт студента. Первый проход отмечает его «В Универе», следующий — «Вне Универа».
На сайте видно, сколько студентов сейчас в университете. Там же добавляют студентов и их фото.

## Запуск

```bash
venv\Scripts\python.exe main.py
```

Откройте http://localhost:8000.

1. Вкладка «Студенты»: добавьте студента.
2. Нажмите «Загрузить фото» или «Фото с камеры» (студент должен стоять перед камерой). Лучше 2–3 фото.
3. Пройдите перед камерой. На вкладке «Дашборд» появится «Вошёл».

## Файлы

| Файл | Что делает |
|---|---|
| `config.py` | Настройки: какая камера, порог похожести, пауза между проходами |
| `database.py` | База SQLite: таблицы и все SQL-запросы |
| `face_engine.py` | Нейросети: найти лицо, получить «отпечаток», сравнить с базой |
| `camera.py` | Фоновый цикл: кадр → лица → студенты → вошёл/вышел, рисует рамки для live-видео |
| `main.py` | Веб-сервер FastAPI: API для сайта, запуск камеры |
| `static/index.html` | Разметка сайта (Vue-шаблон) |
| `static/app.js` | Логика сайта на Vue: запросы к API, кнопки |
| `static/style.css` | Оформление |

## Как распознаётся лицо

1. **Детекция.** Нейросеть находит на кадре прямоугольники с лицами.
2. **Отпечаток (embedding).** Вторая нейросеть превращает лицо в 512 чисел. У одного человека
   отпечатки похожи даже на разных фото.
3. **Сравнение.** Отпечаток с камеры сравнивается со всеми отпечатками из базы. Похожесть —
   скалярное произведение векторов, от 0 до 1. Если похожесть больше `SIMILARITY_THRESHOLD`
   (0.5), это тот студент.

Фото студента при регистрации не сравниваются напрямую. В базе хранится только отпечаток лица.

## Как работает live-видео

Камера в `camera.py` рисует на каждом кадре рамки: зелёная с именем — студент узнан, красная —
неизвестный. Русские буквы рисуются через Pillow, потому что OpenCV их не поддерживает.
Эндпоинт `/api/camera/stream` отправляет кадры в формате MJPEG — это JPEG-картинки одна за
другой. Браузер показывает такой поток в обычном теге `<img>` как видео, JavaScript не нужен.

## База данных

```
students: id, full_name, group_name, status ('inside'/'outside'), last_seen
faces:    id, student_id, embedding (512 чисел в виде байтов), photo_file
events:   id, student_id, action ('in'/'out'), similarity, time
```

Посмотреть базу можно программой DB Browser for SQLite: файл `data/university.db`.

## API

Документация открывается на http://localhost:8000/docs (Swagger, генерируется автоматически).

| Запрос | Что делает |
|---|---|
| `GET /api/stats` | Сколько студентов в Универе, вне, пришли сегодня |
| `GET /api/events` | Последние проходы |
| `GET /api/students` | Список студентов |
| `POST /api/students` | Добавить студента |
| `GET /api/students/{id}` | Карточка: данные, фото, история проходов |
| `PUT /api/students/{id}` | Изменить ФИО и группу |
| `DELETE /api/students/{id}` | Удалить студента |
| `POST /api/students/{id}/photo` | Загрузить фото |
| `POST /api/students/{id}/photo-from-camera` | Фото с камеры |
| `DELETE /api/photos/{id}` | Удалить одно фото |
| `GET /api/camera/stream` | Live-видео с рамками вокруг лиц (MJPEG) |
| `POST /api/students/{id}/toggle` | Отметить вход/выход вручную |
| `POST /api/reset` | Отметить всех как ушедших |
